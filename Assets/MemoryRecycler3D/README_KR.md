# Memory Recycler 3D Starter (Motion + DayNight Update)

추가된 기능
- 걷기 모션: 팔/다리 스윙, 몸통 흔들림, 코트/가방 보조 흔들림
- 뛰기 모션: 더 큰 보폭과 더 빠른 애니메이션
- 낮/저녁/밤/새벽이 자동으로 순환하는 시간대 시스템
- 시간대에 따라 태양빛, 안개, 주변광, 가로등 밝기 변화
- 우측 상단 UI에 현재 시간대와 시각 표시

사용 방법
1. 기존 `Assets/MemoryRecycler3D` 폴더를 삭제합니다.
2. 이 패키지의 `Assets/MemoryRecycler3D` 폴더만 프로젝트의 `Assets` 안에 넣습니다.
3. Unity에서 `Tools > Memory Recycler 3D > Build Prototype Scene` 실행
4. 생성된 `Assets/MemoryRecycler3D/Scenes/Prototype3D.unity` 씬을 엽니다.

입력
- 이동: WASD
- 달리기: Left Shift
- 상호작용: E
- 아카이브: Tab
- 커서 잠금/해제: Esc

권장 설정
- Player Settings > Active Input Handling = Both
- Unity 6.3 LTS / Universal 3D 프로젝트 기준
