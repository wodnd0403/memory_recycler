# Memory Recycler 3D 7분 발표 스크립트

## 1. Memory Recycler 3D

예상 시간: 15초

안녕하세요. 제가 발표할 프로젝트는 Memory Recycler 3D입니다.  
이 게임은 폐도시를 탐험하며 흩어진 기억 구체를 수집하고, 기억을 복원한 뒤 보존, 삭제, 재가공 중 하나를 선택하는 3D 탐험 퍼즐 프로토타입입니다.  
핵심은 단순한 수집이 아니라, 기록창을 기억 렌즈처럼 사용해 도시의 기억을 다시 읽는 경험입니다.

## 2. 개발 배경

예상 시간: 20초

초기에는 기억 문장의 순서를 맞추는 퍼즐이 중심이었습니다.  
하지만 문장만 UI 안에서 맞추는 방식은 3D 폐도시라는 공간을 충분히 활용하지 못했습니다.  
그래서 발표 버전에서는 퍼즐을 화면 안의 문제에서 끝내지 않고, 실제 월드에 떠 있는 기억 UI와 도시 구조물을 겹쳐 복원하는 방식으로 발전시켰습니다.

## 3. 게임 콘셉트

예상 시간: 20초

플레이어는 처음에는 폐도시에 남은 기억을 처리하는 수거원처럼 보입니다.  
기억 구체를 회수하고, 문장을 복원하고, 그 기억을 남길지 지울지 다시 쓸지 선택합니다.  
하지만 후반에는 중앙 아카이브가 도시의 기억뿐 아니라 플레이어의 선택, 실수, 망설임까지 기록하고 있었다는 구조가 드러납니다.

## 4. 핵심 아이디어: 기억 렌즈

예상 시간: 35초

이 프로젝트의 핵심 아이디어는 기억 렌즈입니다.  
Tab 키로 여는 기록창을 단순 메뉴가 아니라, 세계를 읽는 렌즈로 사용했습니다.  
미처리 기억 근처에는 World Space Canvas 기반의 기억 잔상 UI가 떠 있고, 이 UI는 카메라를 향해 회전합니다.  
플레이어는 Tab 렌즈를 켠 상태에서 화면 중앙 마커와 월드의 기억 잔상, 도시 구조물을 겹쳐 기억을 복원합니다.  
즉, 퍼즐의 정답이 UI 안에만 있는 것이 아니라 3D 공간과 UI 사이에 놓이게 됩니다.

## 5. 게임 진행 흐름

예상 시간: 30초

게임 진행은 네 단계입니다.  
첫째, 푸른 기억 구체를 찾아 E 키로 회수합니다.  
둘째, 회수한 기억을 복원합니다. 일반 기억은 문장 순서 퍼즐로, 특수 기억은 기억 렌즈 퍼즐로 복원됩니다.  
셋째, 복원한 기억을 보존, 삭제, 재가공 중 하나로 처리합니다.  
마지막으로 처리 완료 기억이 3개 이상이면 중앙 아카이브에서 엔딩과 심문으로 진입합니다.

## 6. 기억 렌즈 퍼즐 3종

예상 시간: 35초

이번 발표 버전에서는 세 개의 기억에 특수 렌즈 퍼즐을 적용했습니다.  
MR3D_002 파란 우산은 LensAlign 방식입니다. 기억 잔상 UI를 렌즈 중앙과 일정 시간 맞추면 빈칸이 복원됩니다.  
MR3D_003 지워진 안내 방송은 LensOcclude 방식입니다. 거짓 안내 문장을 도시 구조물과 겹쳐 가려진 단어 아래의 진실을 드러냅니다.  
MR3D_006 수거원의 빈 파일은 Stillness 방식입니다. 렌즈로 빈 파일을 바라본 채 움직이지 않고 기다리면 문장이 열립니다.  
이 세 퍼즐 모두 실패해도 게임이 막히지 않도록 기존 순서 퍼즐 fallback 흐름을 유지했습니다.

## 7. 보존/삭제/재가공 선택

예상 시간: 25초

기억을 복원한 뒤에는 세 가지 선택을 합니다.  
보존은 원문을 그대로 남겨 엔딩에서 증언으로 등장시킵니다.  
삭제는 제목 일부를 가리고, 엔딩에서는 증언 없음처럼 침묵으로 남깁니다.  
재가공은 더 견딜 수 있는 문장으로 바꾸지만, 기록 불일치라는 경고를 함께 남깁니다.  
그래서 같은 기억도 플레이어의 선택에 따라 다른 기록으로 바뀝니다.

## 8. PlayerMemoryLog와 아카이브 심문

예상 시간: 30초

PlayerMemoryLog는 플레이어의 행동을 기록합니다.  
첫 선택이 무엇이었는지, 보존/삭제/재가공 횟수, 퍼즐 오답 횟수, 엔딩까지 걸린 시간, 아카이브 근처에 머문 시간, 그리고 특수 퍼즐을 어떤 방식으로 풀었는지를 남깁니다.  
엔딩에 도달하면 중앙 아카이브는 이 기록을 바탕으로 짧은 자기기록 심문을 진행합니다.  
이 부분에서 게임은 도시의 기억뿐 아니라 플레이어의 플레이 방식까지 기억하고 있었다는 반전을 완성합니다.

## 9. 시스템/클래스 구조

예상 시간: 30초

구현 구조는 역할별로 나누었습니다.  
MemoryManager3D는 기억 데이터, 수집, 복원, 처리 상태를 관리합니다.  
UIManager3D는 HUD, 렌즈 오버레이, 선택 UI, 엔딩과 심문 UI를 담당합니다.  
MemoryLensEcho3D는 월드에 떠 있는 기억 잔상 UI를 만들고 카메라를 바라보게 합니다.  
PlayerMemoryLog3D는 선택, 오답, 체류 시간, 해결 방식을 기록합니다.  
ArchiveTerminal3D는 처리 완료 기억 3개 이상이라는 엔딩 조건과 중앙 아카이브 진입을 담당합니다.

## 10. 시연 영상

예상 시간: 2분 30초

이제 실제 플레이 흐름을 영상으로 보여드리겠습니다.  
영상에서는 먼저 폐도시에서 기억 구체를 회수하고, Tab 기억 렌즈를 켜서 월드에 떠 있는 기억 잔상을 확인합니다.  
그 다음 파란 우산 기억의 LensAlign, 지워진 안내 방송의 LensOcclude, 수거원의 빈 파일의 Stillness 퍼즐을 순서대로 보여줍니다.  
이후 복원된 기억을 보존, 삭제, 재가공 중 하나로 처리하고, 3개 이상 처리한 뒤 중앙 아카이브에 접속합니다.  
마지막으로 아카이브가 플레이어의 선택과 복원 방식을 다시 묻는 자기기록 심문, 그리고 엔딩 화면까지 보여줍니다.

## 11. 한계점 및 개선 방향

예상 시간: 20초

현재 발표 버전에서는 8개 기억 중 3개 기억에 특수 렌즈 퍼즐을 집중 적용했습니다.  
나머지 기억은 기존 문장 복원 방식과 선택 결과 중심으로 동작합니다.  
앞으로는 8개 기억 전체에 각각 다른 렌즈 상호작용을 부여하고, 아카이브 심문도 플레이어의 세부 행동에 따라 더 다양하게 바뀌도록 확장할 수 있습니다.

## 12. 마무리

예상 시간: 10초

정리하면 Memory Recycler 3D는 폐도시의 기억을 복원하는 게임처럼 시작하지만, 마지막에는 플레이어의 선택까지 기록으로 회수합니다.  
기억 렌즈, 월드 스페이스 UI, 선택 기록, 아카이브 심문을 통해 "마지막으로 재활용된 것은 기억이 아니라 플레이어의 선택이었다"는 메시지를 전달하고자 했습니다.  
이상으로 발표를 마치겠습니다.
