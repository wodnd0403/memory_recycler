# Memory Recycler 3D Pre-Demo QA Checklist

발표 시연 영상 촬영 전에 `Assets/MemoryRecycler3D/Scenes/Prototype3D.unity`에서 Play만 눌러 확인할 항목입니다.

## 기억 렌즈 UI

- Tab 기억 렌즈 ON 시 일반 HUD와 현재 목표 패널이 렌즈 프레임을 가리지 않는지 확인한다.
- Tab 기억 렌즈 ON 시 시간대/지역성 HUD와 상호작용 안내가 과하게 겹치지 않는지 확인한다.
- Tab 기억 렌즈 OFF 시 일반 HUD, 시간대 HUD, 상호작용 안내가 정상 복구되는지 확인한다.
- Console에서 `[MR3D LensUI] Lens focus mode ON/OFF` 로그가 출력되는지 확인한다.

## 카메라 시야

- 마우스로 위쪽 시야를 충분히 올려 중앙 아카이브, 큰 구조물, 월드 기억 UI를 바라볼 수 있는지 확인한다.
- 카메라가 과하게 뒤집히거나 바닥 아래로 파고들지 않는지 확인한다.
- MR3D_002 / MR3D_003 / MR3D_006 렌즈 퍼즐을 카메라 제한 때문에 실패하지 않는지 확인한다.
- Console에서 `[MR3D Camera] pitch clamp range min=-40.0 max=80.0` 로그가 출력되는지 확인한다.

## 외곽 폐허 기억 구체

- 외곽 폐허의 `Memory Orb_MR3D_006`이 바닥이나 오브젝트에 파묻히지 않고 보이는지 확인한다.
- MR3D_006 주변의 World Space 기억 잔상 UI가 카메라에서 잘 보이는지 확인한다.
- 플레이어가 근처에 접근했을 때 E 상호작용 안내가 정상 작동하는지 확인한다.
- MR3D_006 수집 후 Stillness 렌즈 퍼즐에 진입할 수 있는지 확인한다.

## 핵심 루프

- 기억 구체를 회수한 뒤 복원 퍼즐 또는 기억 렌즈 퍼즐에 진입할 수 있는지 확인한다.
- 복원 후 보존 / 삭제 / 재가공 선택이 가능한지 확인한다.
- 처리 완료 기억 3개 이상에서 중앙 아카이브 심문과 엔딩까지 진행 가능한지 확인한다.
- UI 패널을 닫은 뒤 플레이어 이동, 카메라, 상호작용이 정상 복구되는지 확인한다.

## 촬영 순서 추천

1. 새 게임 시작 후 HUD가 정상 표시되는지 확인한다.
2. Tab을 눌러 기억 렌즈 ON/OFF 전환을 촬영한다.
3. MR3D_002 LensAlign, MR3D_003 LensOcclude, MR3D_006 Stillness 중 최소 2개 이상을 촬영한다.
4. 보존 / 삭제 / 재가공 선택 UI를 촬영한다.
5. 중앙 아카이브 심문과 엔딩 화면을 촬영한다.
