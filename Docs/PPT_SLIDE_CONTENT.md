# PPT 슬라이드 원고

## Slide 1. Memory Recycler 3D

- 핵심 메시지: 폐도시의 기억을 복원하는 3D 탐험 퍼즐
- 넣을 스크린샷: 타이틀 화면 또는 폐도시 전경
- 화면 텍스트:
  - Memory Recycler 3D
  - 폐도시의 기억을 수집하고, 복원하고, 다시 처리하는 3D 탐험 퍼즐
  - 핵심 루프: 기억 구체 수집 -> 기억 렌즈 복원 -> 선택 처리 -> 중앙 아카이브
- 발표 스크립트:
  - Memory Recycler 3D는 폐도시에서 기억 구체를 수집하고 복원하는 3D 탐험 퍼즐입니다.
  - 단순한 수집 게임이 아니라, 기록창을 기억 렌즈처럼 사용해 도시의 기억을 다시 읽는 경험을 목표로 했습니다.
- 예상 시간: 15초

## Slide 2. 개발 배경

- 핵심 메시지: 문장 순서 퍼즐을 3D 공간 기반 퍼즐로 확장했다
- 넣을 스크린샷: 폐도시 전경, 기억 구체가 보이는 장면
- 화면 텍스트:
  - 기존 문제: UI 안에서만 푸는 문장 순서 퍼즐은 공간 활용이 약함
  - 개선 방향: 폐도시 위에 뜬 기억 UI와 Tab 렌즈를 겹쳐 복원
  - 목표: 3D 탐험과 퍼즐이 같은 화면에서 느껴지게 만들기
- 발표 스크립트:
  - 초기 퍼즐은 문장 조각 순서 맞추기에 가까웠습니다.
  - 하지만 3D 폐도시라는 공간을 살리기 위해, 단서가 월드 안에 떠 있고 Tab 렌즈로 겹쳐 읽는 방식으로 발전시켰습니다.
- 예상 시간: 20초

## Slide 3. 게임 콘셉트

- 핵심 메시지: 도시는 기억되고, 플레이어도 기록된다
- 넣을 스크린샷: 기억 구체 회수 장면 또는 중앙 아카이브 원경
- 화면 텍스트:
  - 플레이어 역할: 기억 수거원
  - 목표: 기억 수집, 문장 복원, 보존/삭제/재가공 선택
  - 반전: 중앙 아카이브는 플레이어의 선택과 실수도 기록
- 발표 스크립트:
  - 플레이어는 도시의 기억을 처리하는 수거원입니다.
  - 하지만 후반에는 아카이브가 기억뿐 아니라 플레이어의 선택, 오답, 망설임까지 기록하고 있었다는 점이 드러납니다.
- 예상 시간: 20초

## Slide 4. 핵심 아이디어: 기억 렌즈

- 핵심 메시지: Tab 기록창은 메뉴가 아니라 세계를 읽는 렌즈다
- 넣을 스크린샷: Tab 렌즈 OFF/ON 비교, 중앙 마커가 보이는 화면
- 화면 텍스트:
  - Tab = 기억 렌즈 ON/OFF
  - World Space Canvas 기억 잔상 UI
  - 카메라를 바라보는 billboard UI
  - 화면 중앙 마커와 월드 단서를 겹쳐 복원
- 발표 스크립트:
  - 이 프로젝트의 가장 중요한 아이디어는 기억 렌즈입니다.
  - Tab으로 여는 기록창은 단순 로그북이 아니라, 월드에 떠 있는 기억 잔상과 도시 구조물을 겹쳐 읽는 렌즈 역할을 합니다.
  - 이로써 퍼즐의 정답이 UI 안이 아니라 3D 공간과 화면의 겹침 사이에 놓이게 됩니다.
- 예상 시간: 35초

## Slide 5. 게임 진행 흐름

- 핵심 메시지: 수집, 복원, 선택, 심문으로 루프가 닫힌다
- 넣을 스크린샷/그림: 4단계 흐름도
- 화면 텍스트:
  - 1. 푸른 기억 구체 회수
  - 2. 문장/렌즈 퍼즐로 복원
  - 3. 보존/삭제/재가공 선택
  - 4. 처리 완료 3개 이상 -> 중앙 아카이브 심문/엔딩
- 발표 스크립트:
  - 진행 흐름은 네 단계입니다.
  - 기억을 회수하고, 복원하고, 처리 선택을 합니다.
  - 처리 완료 기억이 3개 이상이면 중앙 아카이브가 열리고, 엔딩과 자기기록 심문으로 이어집니다.
- 예상 시간: 30초

## Slide 6. 기억 렌즈 퍼즐 3종

- 핵심 메시지: 겹치기, 가리기, 멈추기로 기억을 복원한다
- 넣을 스크린샷: MR3D_002, MR3D_003, MR3D_006 렌즈 장면 3분할
- 화면 텍스트:
  - MR3D_002 파란 우산: LensAlign
  - MR3D_003 지워진 안내 방송: LensOcclude
  - MR3D_006 수거원의 빈 파일: Stillness
  - 일반 기억은 Sequence 퍼즐 fallback 유지
- 발표 스크립트:
  - 발표 버전에서는 세 개의 기억에 특수 렌즈 퍼즐을 적용했습니다.
  - 파란 우산은 기억 잔상을 중앙에 맞추고, 안내 방송은 구조물과 겹쳐 거짓 단어를 가리며, 빈 파일은 움직이지 않고 바라봐야 열립니다.
  - 기존 순서 퍼즐도 fallback으로 유지해 진행이 막히지 않게 했습니다.
- 예상 시간: 35초

## Slide 7. 보존 / 삭제 / 재가공

- 핵심 메시지: 선택은 엔딩의 증언 방식을 바꾼다
- 넣을 스크린샷: 선택 UI, 처리 결과 텍스트
- 화면 텍스트:
  - 보존: 원문 증언 유지
  - 삭제: 제목 일부 마스킹, 증언 없음
  - 재가공: 부드러운 문장으로 대체, 기록 불일치
- 발표 스크립트:
  - 기억을 복원하면 세 가지 방식으로 처리할 수 있습니다.
  - 보존은 원문을 남기고, 삭제는 침묵으로 남기며, 재가공은 견딜 수 있는 이야기로 바꾸지만 기록 불일치를 남깁니다.
  - 같은 기억도 선택에 따라 다른 엔딩 증언으로 이어집니다.
- 예상 시간: 25초

## Slide 8. PlayerMemoryLog와 아카이브 심문

- 핵심 메시지: 아카이브는 플레이어의 행동까지 기억한다
- 넣을 스크린샷: 아카이브 자기기록 심문 UI, 행동 기록 요약
- 화면 텍스트:
  - 첫 선택 기록
  - 보존/삭제/재가공 횟수
  - 퍼즐 오답과 해결 방식
  - 엔딩까지 걸린 시간, 아카이브 체류 시간
  - 엔딩 전 자기기록 심문
- 발표 스크립트:
  - PlayerMemoryLog는 플레이어의 행동을 별도 기록으로 남깁니다.
  - 어떤 선택을 먼저 했는지, 몇 번 틀렸는지, 어떤 렌즈 방식으로 풀었는지까지 기록합니다.
  - 엔딩에 도달하면 아카이브가 이 기록을 바탕으로 플레이어에게 다시 질문합니다.
- 예상 시간: 30초

## Slide 9. 시스템/클래스 구조

- 핵심 메시지: 주요 클래스가 수집, 렌즈, 기록, 엔딩을 분담한다
- 넣을 스크린샷/그림: 클래스 구조 다이어그램
- 화면 텍스트:
  - MemoryManager3D: 기억 상태와 처리 흐름
  - UIManager3D: HUD, 렌즈, 선택, 심문, 엔딩 UI
  - MemoryLensEcho3D: 월드 스페이스 기억 잔상
  - PlayerMemoryLog3D: 선택/오답/해결 방식 기록
  - ArchiveTerminal3D: 중앙 아카이브 진입과 엔딩 조건
- 발표 스크립트:
  - 구현은 기능별 책임을 나눠 관리했습니다.
  - MemoryManager3D가 기억 상태를 관리하고, UIManager3D가 표시와 패널을 담당합니다.
  - MemoryLensEcho3D는 월드에 떠 있는 기억 UI를 만들고, PlayerMemoryLog3D와 ArchiveTerminal3D가 플레이어 기록과 엔딩 조건을 연결합니다.
- 예상 시간: 30초

## Slide 10. 시연 영상

- 핵심 메시지: 한 루프로 핵심 재미와 엔딩 반전을 보여준다
- 넣을 자료: 2분 30초 시연 영상
- 화면 텍스트:
  - 수집 -> 렌즈 복원 -> 선택 처리 -> 아카이브 심문 -> 엔딩
- 발표 스크립트:
  - 이제 실제 플레이 흐름을 영상으로 보여드리겠습니다.
  - 영상은 기억 구체 회수부터 세 가지 렌즈 퍼즐, 선택 처리, 중앙 아카이브 심문과 엔딩까지 이어집니다.
- 예상 시간: 2분 30초

## Slide 11. 한계점 및 개선 방향

- 핵심 메시지: 발표 버전은 3개 특수 퍼즐에 집중했고, 이후 전체 기억으로 확장 가능하다
- 넣을 스크린샷/그림: 현재 구현/향후 확장 표
- 화면 텍스트:
  - 현재: 8개 기억 중 3개 특수 렌즈 퍼즐
  - 향후: 8개 기억 전체에 고유 렌즈 상호작용 추가
  - 심문 문항과 엔딩 반응 다양화
  - 렌즈 힌트/성공 문구를 데이터화
- 발표 스크립트:
  - 현재는 발표 임팩트를 위해 세 개 기억에 특수 퍼즐을 집중했습니다.
  - 향후에는 모든 기억에 고유 렌즈 상호작용을 넣고, 아카이브 심문도 더 다양한 플레이 기록을 반영하도록 확장할 수 있습니다.
- 예상 시간: 20초

## Slide 12. 마무리

- 핵심 메시지: 마지막으로 재활용된 것은 기억이 아니라 플레이어의 선택이다
- 넣을 스크린샷: 엔딩 화면 또는 아카이브 터미널
- 화면 텍스트:
  - 기억 렌즈: UI와 3D 공간을 겹치는 퍼즐
  - 선택 기록: 보존/삭제/재가공의 결과
  - 아카이브 심문: 플레이어의 행동까지 기록
  - 결론: 게임이 플레이어를 기억한다
- 발표 스크립트:
  - Memory Recycler 3D는 폐도시의 기억을 복원하는 게임처럼 시작하지만, 마지막에는 플레이어의 선택까지 기록으로 회수합니다.
  - 기억 렌즈와 아카이브 심문을 통해 게임이 플레이어를 기억한다는 구조를 완성하고자 했습니다.
  - 감사합니다.
- 예상 시간: 10초
