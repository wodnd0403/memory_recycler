# 2분 30초 시연 영상 구성안

## 목표

- 7분 발표 중 2분 30초를 시연 영상으로 사용한다.
- 영상 하나만으로 `수집 -> 렌즈 복원 -> 선택 처리 -> 아카이브 심문 -> 엔딩` 흐름이 이해되게 만든다.
- 실제 구현된 기능만 촬영한다.
- 영상 길이는 2분 30초를 목표로 하고, 최대 3분을 넘기지 않는다.

## 촬영 전 준비

- 씬: `Assets/MemoryRecycler3D/Scenes/Prototype3D.unity`
- Play만 눌러 테스트 가능한 상태에서 촬영한다.
- 새 게임 또는 저장 초기화 상태로 시작한다.
- 영상에는 가능하면 마우스 커서와 UI가 보이게 한다.
- 오디오가 불안정하면 BGM보다 화면 중심으로 촬영하고, 발표자가 옆에서 설명한다.

## 권장 영상 타임라인

| 시간 | 장면 | 보여줄 기능 | 촬영 포인트 |
|---:|---|---|---|
| 0:00~0:08 | 시작 화면/폐도시 진입 | 게임 분위기 | 타이틀 또는 폐도시 전경을 짧게 보여준다 |
| 0:08~0:20 | 기억 구체 접근과 회수 | E 상호작용, 기억 수집 | 푸른 기억 구체와 HUD 안내가 함께 보이게 한다 |
| 0:20~0:32 | Tab 기억 렌즈 ON/OFF | 렌즈 오버레이 | OFF/ON을 비교해 렌즈가 메뉴가 아니라 화면 장치처럼 보이게 한다 |
| 0:32~0:50 | MR3D_002 LensAlign | 파란 우산 겹치기 | 월드 스페이스 기억 UI를 중앙 마커에 맞추고 성공 문구를 보여준다 |
| 0:50~1:06 | MR3D_003 LensOcclude | 안내 방송 가리기 | 건물/구조물 방향을 바라보며 렌즈 판정 성공 장면을 보여준다 |
| 1:06~1:25 | MR3D_006 Stillness | 멈추기 퍼즐 | 움직이지 않고 5초 유지되는 타이머와 성공 순간을 보여준다 |
| 1:25~1:40 | 보존/삭제/재가공 선택 | 선택 결과 | 세 선택지가 보이게 하고 최소 하나의 처리 결과 문장을 보여준다 |
| 1:40~1:54 | 중앙 아카이브 터미널 | 3개 처리 후 접속 | 터미널 비주얼, E 상호작용, 접속 가능 상태를 보여준다 |
| 1:54~2:10 | 아카이브 자기기록 심문 | 플레이어 행동 기록 | 첫 선택/해결 방식 질문이 보이게 한다 |
| 2:10~2:30 | 엔딩 화면 | 행동 기록과 증언 | 엔딩 화면을 짧게 보여주고 마무리한다 |

목표 길이는 2분 30초다. 엔딩 화면 가독성을 위해 늘리더라도 최종 편집본은 3분을 넘기지 않는다.

## 촬영 컷 구성

### 컷 1. 폐도시와 목표

- 화면: 폐도시 전경, HUD 목표 문구
- 의도: 프로젝트가 3D 탐험 게임이라는 것을 빠르게 전달
- 발표 멘트: "먼저 폐도시에서 기억 구체를 찾습니다."

### 컷 2. 기억 구체 회수

- 화면: 푸른 기억 구체, E 상호작용, 회수 후 기록 상태
- 의도: 핵심 루프의 시작점 설명
- 발표 멘트: "E 키로 기억을 회수하면 기록 대상이 됩니다."

### 컷 3. Tab 기억 렌즈

- 화면: Tab OFF와 ON 비교, 중앙 마커, 렌즈 안내
- 의도: Tab이 메뉴가 아니라 렌즈라는 점 강조
- 발표 멘트: "Tab을 누르면 기록창이 아니라 기억 렌즈가 켜집니다."

### 컷 4. LensAlign

- 화면: MR3D_002 파란 우산 기억 잔상과 중앙 마커 정렬
- 의도: 화면과 월드 UI를 겹쳐 푸는 첫 퍼즐
- 성공 문구를 반드시 1초 이상 보여준다.

### 컷 5. LensOcclude

- 화면: MR3D_003 안내 방송 기억 잔상을 구조물 방향에 맞춤
- 의도: 거짓 단어를 가리고 진실 문장이 드러나는 느낌
- 구조물이 뒤에 보이게 각도를 잡는다.

### 컷 6. Stillness

- 화면: MR3D_006 빈 파일 기억 잔상, 정지 타이머
- 의도: 입력하지 않는 행동 자체가 퍼즐이라는 점 전달
- 타이머가 0에서 5초로 차는 과정은 2배속 편집 가능.

### 컷 7. 선택 처리

- 화면: 보존/삭제/재가공 선택 UI
- 의도: 플레이어 선택이 기록을 바꾼다는 점 전달
- 세 선택지를 모두 보여준 뒤 하나를 선택한다.

### 컷 8. 중앙 아카이브

- 화면: 중앙 아카이브 터미널, 접속 안내, E 입력
- 의도: 처리 완료 3개 이후 엔딩 장소로 진입
- 터미널 비주얼과 라벨이 보이도록 정면에서 촬영한다.

### 컷 9. 자기기록 심문

- 화면: 아카이브가 플레이어의 첫 선택 또는 렌즈 해결 방식을 묻는 UI
- 의도: "게임이 플레이어를 기억한다"는 반전 전달
- 문제와 선택지, 답변 후 반응을 짧게 보여준다.

### 컷 10. 엔딩

- 화면: 엔딩 본문, 수거원 행동 기록, 아카이브 증언
- 의도: 선택과 행동 기록이 엔딩에 반영됨을 보여준다.
- 마지막 2초는 엔딩 화면에 머문다.

## 편집 가이드

- 불필요한 이동 시간은 과감히 자른다.
- Stillness 5초 대기는 2배속 또는 컷 편집으로 줄여도 된다.
- 각 성공 문구는 최소 1초 이상 유지한다.
- 엔딩 텍스트는 너무 빠르게 넘기지 않는다.
- 영상에 자막을 넣는다면 네 문장만 사용한다.
  - "Tab = 기억 렌즈"
  - "월드에 떠 있는 기억 잔상"
  - "선택은 기록을 바꾼다"
  - "아카이브는 플레이어도 기억한다"

## 실패 시 대체 촬영안

- LensOcclude가 특정 위치에서 잘 안 잡히면 중앙 아카이브나 큰 건물 구조물을 배경으로 다시 촬영한다.
- Stillness 타이머가 리셋되면 키보드와 마우스를 완전히 놓고 촬영한다.
- 저장 상태 때문에 퍼즐이 이미 복원되어 있으면 새 게임 또는 저장 초기화 후 다시 촬영한다.
- 엔딩 조건이 막히면 처리 완료 기억 3개 이상인지 확인한다.
